# 七宝 AI 数字人 · 实时互动直播

实时互动直播虚拟主播 —— 弹幕问答实时响应，口型与语音同步，多人设自由切换，为直播带货而生。

**在线展示**：https://opc007.github.io/ai-digital-human-showcase/

## 亮点

- 💬 **实时弹幕互动**：观众提问秒级响应，自然口语回答，支持打断追问
- 👄 **口型实时同步**：自研实时口型驱动，每一帧嘴型都由语音实时生成
- 🎭 **多人设切换**：温柔 / 飒爽 / 知性多档人设，一键切换
- 🛡️ **内容安全**：四层内容安全隔离，开播不翻车
- 🎬 **动作库**：挥手 / 点头 / 比心 / 飞吻等预设动作，弹幕关键词触发
- 💰 **低成本**：全链路自研，连续开播无压力
